## 物理假设与诊断规律的实际结论

原模型多处body gravcomp直接在引擎层抵消重力，绕过执行器实际承担该部分负载的要求。本轮关闭该项及外加力，再用受有限执行器出力约束的内部重力前馈；因此既能研究可执行任务，又必须明确有效出力/轮摩擦是当前假设，不能声称真实硬件已标定。严格来源缺口独立保留。

数据能力记录已按模型、控制器、任务、来源及分布绑定；范围外和硬件请求返回unknown。真实任务质量门、保存力重建、观测动作对齐可复用。D事后“保持横移>15mm”预警曾命中8个失败，但在W前冻结后出现误报1、漏报1、正确无警成功5、无保持状态不可评3，未获得前瞻确认。W误差X/Y/Z同时变化，也未形成单轴因果阈值。这些失败应保留为回归证据，不能写成已解决的通用能力判定规律。
