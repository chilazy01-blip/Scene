## 最终方向

**依托自有场景生成器，建设能持续批量生成高质量full-body任务示范，并通过独立全身任务学习验证的数据生产系统。** 主线仍为场景生成→可执行任务→自动采集→质检/标准导出→任务学习验证→批量生产。

当前目标身体为人形全身协调；FB0已固定G1 29身体+14手、Decoupled WBC与分层动作，FB1已通过。人体动捕配对或特定拟人风格保留为可选扩展，真机资格单独验证。优先复用成熟全身控制器，不要求每个生成场景先独立训出行走策略。
