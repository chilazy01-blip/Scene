# Full-body仿真训练数据：路线图与近期顺序

更新：2026-09-28。用户已同意以人形机器人全身协调执行任务为近期主线，并要求重设近期、中期和最终目标。以本页、[分阶段目标与验收](EMBODIED_FULL_BODY_GOALS_20260928.md)及AGENT顶部为准。完整调整前路线已[归档](history/embodied_full_body_goals_20260928_before/MANIFEST.json)，历史单臂成果与费用全部保留。

## 最终方向

**依托自有场景生成器，建设能持续批量生成高质量full-body任务示范，并通过独立全身任务学习验证的数据生产系统。** 主线仍为场景生成→可执行任务→自动采集→质检/标准导出→任务学习验证→批量生产。

当前目标身体为人形全身协调；FB0已固定G1 29身体+14手、Decoupled WBC与分层动作，FB1已通过。人体动捕配对或特定拟人风格保留为可选扩展，真机资格单独验证。优先复用成熟全身控制器，不要求每个生成场景先独立训出行走策略。

## 三阶段目标

|阶段|目标|验收重点|
|---|---|---|
|近期|一个固定本体、一类完整全身任务，打通原生环境与至少一套自生成场景的小规模数据闭环|完整执行、全身字段与接触、同步导出和真实读取、固定独立初态复验；一条成功是中间节点|
|中期|同一本体扩展多任务族和有效场景分布，形成可复用采集系统并检验数据价值|建议携物移动/不同高度取放/双手分工三类；批次质量与合格产量、开发验证隔离、至少一个任务族有独立任务学习收益，其他逐项报告|
|最终|按声明任务与分布持续批量生产可用的全身训练数据|跨批次质量与覆盖稳定、成本和人工介入可控、可恢复追溯、训练收益可复现|

阶段以证据推进，数量和日历承诺由实测吞吐与预算决定。验收不只看总条数，不把局部姿态/一步预测改善替代完整任务收益。

## 近期固定优先顺序

|步骤|主要工作与交付|当前状态|依赖|
|---|---|---|---|
|FB0 本体/控制器/接口定型|候选适配证据、固定版本与权重清单、状态/动作/历史映射、全身接触角色、任务模板、完整受限准入方案与资源估算|完成：G1/Decoupled WBC/43通道及有限包固定|已获同意的full-body路线|
|FB1 原生全身控制准入|验证站立、步行/停步、身体降高、手臂及手动作，保存恢复与物理审计|通过：20秒降高/步行/停步/双臂手协同及独立审计|FB0与实际准入条件|
|FB2 一条完整任务及数据|接近→取物→起身→携物移动→放置；全身状态/分层动作/视觉/接触同步导出和实际消费者检查|0条；旧固定物理任务关闭；全路径参考/反馈专家矩阵未通过，下一项联合可行性与阶段协调器|FB1|
|FB3 自有场景与小批复验|生成器接入同一任务；冻结开发/独立初态矩阵、分母、质量及累计退出；结果和成本闭合|未准入|FB2|
|FB4 多任务/多场景扩展|有效任务参数化、自动采集与恢复、固定批次产量/质量报告|中期规划|FB3|
|FB5 独立任务学习验证|固定控制栈与训练预算，比较数据覆盖/规模对全身任务成功的作用|中期规划|合格开发数据及隔离评测|
|FB6 批量生产验收|多批次质量/成本/人工介入/恢复和学习收益验收|最终目标|FB4–FB5证据|

首个任务模板建议为轻量刚性物体的取起、短距离携带与放置，包含身体高度变化和行走/操作协调。最终物体、质量、距离、支撑高度及双手方式按FB0能力固定；先验证组成能力再连接完整任务。场景中的腿部自由支撑和真实物体交互不能用姿态回放或物体瞬移代替。
