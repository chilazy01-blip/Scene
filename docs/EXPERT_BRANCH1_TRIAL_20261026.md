## 实现的可复用部分

代码位于 `sage/experiments/embodied_expert_branch1_v1/`。

- `contracts_v2.py`、`feedback_v3.py`：按抓紧、试提、抬升、悬停、持物行走、放置、释放和稳定阶段记录条件、首次可观测异常、接触与状态窗口，并绑定真实源文件。
- `spatial_feedback.py`：将实际腕姿态、上一状态发出的参考、具名手关节和原生接触力按时间对齐，减少仅看末点判断原因的问题。
- `experience_v2.py`：按本体、控制器依赖、资产、模型 SHA、case 内容 SHA、质量与抓区等条件检索；区分已验证完整技能、局部经验、负例和未实测假设。
- `promotion.py`：直接读取独立验收证据决定是否可晋升。所有记录禁止自动部署。历史两杯可在原范围引用；本轮五条瓶负例只能用于诊断，S02/S03 完整瓶技能检索均为空。
- `strategies/`：保存实际专家生成、实际测试的四个冻结候选，不把尚未实测的旧 V011 视为已验证代码。

共完成 **4 次真实 Codex 专家设计调用**，均正常返回，无容量错误。专家根据上一版真实失败证据提出下一版参考控制，再由受保护原生 runner 实测；没有让设计调用直接积分。调用用量的缓存部分包含在输入 token 内，具体记录见 `EXPERT_ALL_CALLS_REVIEW.json`；主编排用量未计入该报告，未虚报总美元费用。

经验检索与修订形成了工程层面的反馈链，但本轮没有策略训练、模型权重更新、隔离测试或生成器生产接入，不能称已证明有效自进化。生成器反馈接口和等预算收益验证仍是后续工作。

## 质量检查与已纠正问题

原生机器人、模型、八项任务门和姿态门保持冻结：G1 身体 SONIC29 加原生 14 手 PD，原增益/力矩限幅、加载手参考上限 .65；NoSlip 在第 3960 物理步由 0 切为 3。瓶仍为假设 200 g 的空刚体、颈部/瓶盖抓区。S02/S03 是已有自有生成布局，不能当作新生成任务泛化证明。

每条试验保留独立 NN、原生 PD、接触/几何、状态与时间链、力重建、完整实际视频解码和主 agent 抽样关键帧复核。合格杯额外完成从原初态的全 43 控制连续复验：状态误差 0，数值警告 0，并检查 NPZ 维度、有限值和连续性。负例不冒充完整成功，也不为重复确认负例追加连续积分。人工检查的是抽样实际帧，不声称逐帧人工观看。

开发中发现并保留了三个接口/审计问题：

1. `object_local_m` 实际是物体相对右腕坐标，初版标签曾误写根坐标，已在正式反馈纠正。
2. 原生手关节与身体交错，左手 qpos 地址为 29–35，右手为 43–49。初版硬切片误把右臂标为左手；正式反馈 V3 从模型具名地址读取并与独立 schema、完整 TRACE 逐值核对。原始完整状态、右手、实际控制和 NPZ 未受影响。
3. 旧审计未重建执行器添加的 tick/最后手参考，且直接比较 Python tuple 与 JSON list，不能复现新增契约；新观察审计重建实际公开观测并使用相同 JSON 规范化。其第一版又把预热 tick 全假定为 −1，新增 `audit_metadata_v4.py` 按冻结 engine 的 −10…−1、各 4 步独立补证，保留旧失败报告。最终仍要求全部控制/因果门通过；负例的完整任务门继续为 false。

契约、检索与迁移守护 17 项测试，加成本预留保护 1 项通过；四版候选另有针对实际记录状态的零积分检查。首次 pytest 因环境中无关 ROS 自动插件加载失败，保留日志，禁用其自动加载后通过，未安装依赖。新源码完成语法与来源核对；实验前断点已有的两个旧诊断脚本语法错误保留，没有声称全仓测试通过。暂存差异检查另发现五个已绑定源码末尾的额外空行；为保持实际执行/审计 SHA，保留原字节并在归档验证中列明，不宣称该检查无告警。

## 成本、退出与结论

六次 raw 合计 **47012** 步，加杯连续复验 **8536**，本轮新增 **55548 native physics**。承接 239138，累计 **294686**；7 项实际预留全部结算。去重新合格数为 0，单位新增合格轨迹成本未定义，不能记为 0。

本轮最多新增 120000 步，窗口为 2026-10-26 23:40:31 至 10-27 03:40:31 CST。后续 PLAN 在同一账本内将最低 QA 余量提高到 60 分钟，新试跑最晚准入 02:40:31；V004 后停止新增试跑，完成独立 QA 和归档。没有重置时限、复活旧轮额度或按版本数强制结束。

目前值得保留的是：冻结抓持预载可以改善局部搬运；入口条件与持续不变量必须分开；静态载荷阈值、暂停开手甚至小幅腕参考回座都不能自行保证释放成功。下一轮若继续，应先明确实际腕参考跟踪与瓶盖接触几何如何影响交接，考虑有界对照诊断，并继续保留完整失败成本。此建议尚未执行，不把本轮接口落地等同于产量收益。
