## 新定位的控制链缺陷

完整重放 D7 的 **601 次控制决策**，目标、最终命令和阶段决策误差均为 0，精确复现最后一次拒绝。分层几何检查如下：

被拒绝命令的右拇指末节与箱体右侧壁，在独立几何模型中产生 **18.4468mm 穿入**，超过原 **5mm** 上限。该命令在执行前已被拦截，不能写成机器人已经发生这次穿入。

具体问题是：**逐关节分别限制速度与加速度，会改变关节之间的运动比例，使原本可行的协调路径变成另一条路径。** 当前检查能拒绝坏命令，但限速器自身没有保证输出仍在可行路径上。因此，单独验证 IK 目标，或者逐帧零速度检查，并不足以验证实际带历史状态的控制链。此例的速度前馈目标通过，不能把最后的失败笼统归因于前馈。
