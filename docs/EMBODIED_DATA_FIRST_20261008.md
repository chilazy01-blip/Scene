## 接下来的生产线路

1. **外部数据验证训练工具。** 已完成数值子集；完整视觉学习仍需另外的数据与评测。外部数据进入自己的外部训练目录，不计为自产产量。
2. **在原生场景证明完整任务可以真的执行。** 先核验场景、本体、控制接口与专家来源，按实际动作推进物理；必须记录失败，不能逐帧摆姿态模拟成功。合格采集器可以来自规划器、脚本专家或学习策略，不强制每条数据都依赖一条既有示范。
3. **完成FB2的数据交付。** 一条实际完整全身任务，加同步公开观察/动作、独立物理和数据审计、标准导出、真实消费者。成功画面或某一个任务布尔值不足以通过。
4. **接入自己的生成场景。** 先冻结一批独立场景与初态，收集全部成功/失败分母，按FB3验收；不能把原生场景成功直接推广为生成场景可用。
5. **验证学习价值后扩大产量。** 在没有参与训练的场景和初态上评测完整任务，比较等量数据和增加数据的收益，再决定扩产。

旧协调控制器保留为候选工程成果和回归证据，不再是自动恢复的默认线路。其局部离线通过不等于完整动态通过；旧D7保持关闭，旧D8增额方案不因本次路线批准而生效。
