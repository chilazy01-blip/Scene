## 可复用修改及验证

代码在 `sage/experiments/embodied_expert_task_v1/`：

- `source_demo.py`：严格检查完整源 episode、43 维动作、31 维上肢/手目标、有限值及真实仿真时钟；只用第一状态初始化；隔离配置 CPU ONNX。
- `quality.py`：逐步基座高度/倾角、关节范围、速度及按角色区分的接触/穿透检查。它是外部诊断模块，不能代替完整 FB2 验收器。
- `recording.py`：保存编译后的 MuJoCo 二进制模型并逐数组核对，保留版本和源文件要求。
- `admission.py`：分别判断状态展示、动作回放一致与任务完成，不能继承为本项目通过。

输入缺帧/时钟间隙/非有限动作/任务错配、合法输入与二进制模型往返共 6 项检查通过；真实发布清单的 4 项来源判断检查通过。没有训练、GPU 作业或新增仿真渲染。

独立审计前两版发现普通 `MODEL.xml` 重建的模型与运行时不等价；其质量、惯性、几何及其他数组有差异，不能归因于单纯舍入误差。使用原冻结源 XML 与原生初始化重建后，全部保存接触距离精确复现。新二进制快照往返逐数组完全一致。早期审计、两次预检报告工程错误、图表语法修订、来源环境名匹配修复，以及目录响应超过 2 MiB 后的部分下载均保留；不抹除失败或返还费用。
