# 长跑持续执行修订：计划、调度与整轮结束检查

2026-10-11，用户在指出约十二小时长跑只执行六十一分钟后，明确要求“那就去落实这些要求”。本修订实现持续执行机制、开发预算调配、失败接续、断点恢复和退出验证。原完整资源授权继续有效；原物理方法的关闭记录、质量要求、累计成本和截止时间保留。

代码位于 `sage/experiments/embodied_continuous_v1/`。原双管线目录 `native_parallel_12h_20261011`（R）只读保留；相邻的 `continuous_execution_20261011`（S）保存本次修订的 PLAN、AUTHORIZATION、STATE、CONTINUATION_CHECK、jobs 和 reports。S 导入 R 的完整账本及科学失败计数，修订工程成本继续计入同一资源包。

## 修复的具体问题

原 `tools/admission.py` 以每路两次迁移限制后继，原 `tools/finalize.py` 以两路都关闭作为整轮封存依据。两项条件合在一起，造成预算剩余充足时仍提前结束。此前将十二小时仅解释为上限，没有落实用户要求的持续自主推进。

新入口把整轮状态、方法状态和工作进程状态分开。普通作业结束会调度后继；方法关闭会阻止该方法的新物理试验，同时继续证据分析、工程修订及其他有效工作。失败次数不会因阶段、代码修订、进程或名称变化清零。

## 整轮结束条件

`controller.close()` 是新入口唯一的 CLOSURE 写入点。它在文件锁内重新评估最新状态，调用者不能传入一个自称有效的退出结论。

允许结束的情况为：

- 有证据绑定的完整目标和独立验收均通过。
- 有明确用户停止指令的证据。
- 到达原始截止时间。
- 实际可用于全部工作的资源耗尽。目前自动识别全局服务预算；单独耗尽任务次数或物理积分额度仍允许零物理分析。其他硬资源阻塞必须补齐证据，不能由队列为空推断。
- 有证据的真实外部阻塞，列明所有待执行工作，且授权范围内的替代工作也无法继续。

有活动进程时先终止或完成、核账，再封存。阶段配额、方法关闭、依赖错误、作业超时、报告生成、队列为空都不是整轮结束依据。退出检查保存资源余量、方法状态、待执行工作的阻塞原因和退出理由；无效封存请求写入 `REJECTED_CLOSURE.json`。

`replan` 表示协调者需要根据证据补充具体工作。CLI 的退出码 75 是交还协调者继续规划，不是实验结束。协调者应实现修复或用 `extend` 登记有输入绑定、成本预留和失败后继的新任务，再调度执行。不得把它汇报成目标完成或整轮封存，也不允许用空转填满时间。

## 预算与自主范围

各项上限取“原批准新增包上限”和“原批准累计上限减历史基线”的较小值。已消耗的 8 次任务及所有计算成本导入，不重新申请、不清零。

|任务池|原完整包额度|本次导入后的余量|使用规则|
|---|---:|---:|---|
|原生／迁移／生成开发共享池|10|2|取消阶段两次迁移硬限；只供仍获科学准入的方法|
|独立共同比较|4|4|控制器冻结，不能转作开发|
|最终新测试|6|6|生产准入、冻结后新样本、首失败关闭；不能转作开发|

共享的是开发额度，方法科学退出继续生效。当前 A 的三次、B 的两次科学失败和两路既有关闭状态完整继承；本次机制修订不自动重开它们。比较、最终测试分别预留积分、策略、渲染和服务成本，导出与封存另保留服务及渲染预算。每个实际作业还必须申报全部资源；预留量不会因工程修订清零。

以下工作自主执行：依赖和脚本修复、关节名称／单位／时序合同、数据读取验证、已有轨迹的因果分析、可逆工程修订、最小回归和具体后继方案准备。新接触技能、训练、已关闭物理方法的重开、机器人或验收标准变化，以及提高硬预算或重置截止时间，继续属于实质范围变化。把这些边界写入 PLAN 的 `authorized_scopes` 和 `scope_boundaries`，不以空泛的“技术自主”冒充具体物理准入。

物理作业需要绑定独立准入合同：方法 ID、范围、输入哈希、质量要求。比较还需要冻结控制器；最终测试还需要生产准入和全新样本。准入检查发生在启动子进程之前。已关闭方法或缺少合同的工作会被拒绝，并留给其他工作继续调度。

## 失败与恢复

每个普通任务必须登记失败后继，按保存证据、查明最早偏离、可检验解释、有限修复、回归验证的顺序推进。工程失败、科学失败、超时和中断分开记录。物理失败只影响对应方法；工程失败不自动增加科学失败次数。历史失败重新分类须有证据，不能为了继续运行而抹除。

原 A_native_01 的运行时敏感性不等于已证明它是纯工程错误：A 没有固定依赖锁文件，因此本次保持它的原科学计数。B 的退出则明确记录为阶段分配耗尽，未达到三次科学失败。详细复核在 S/reports/FAILURE_CLASSIFICATION.json。

新执行器采用串行有界子进程，单进程最多四核、5.5 GiB 地址空间、900 秒，低于原合计八核／十二 GiB上限。独立 `timeout` 在协调进程中断后仍限制工作进程；正常结束或超时后清理同进程组子进程。30 秒心跳、原子状态写入和文件锁用于断点与防重复启动。

子进程预留先落盘，完成后核账。没有可信回执的中断按完整预留保守扣账，并转入诊断；不盲目重跑。当前物理命令接口也采用完整预留保守扣账，不将该上界伪称实际积分计数。工程服务秒记录实测运行时间，并保留超时及失败成本。

增加新任务使用 STATE 中追加的工作队列和事件记录；原计划、方法状态、截止时间、已完成任务和原账本均不改写。重复任务 ID、缺少输入绑定、未授权范围和负数／非有限资源值会被拒绝。

## 已登记的后继

S 初始工程链为：旧证据完整性核验 → 失败分类复核 → 具体后继合同 → 接续审计；任一失败进入工程诊断。后继合同明确列出：

1. 从 B 的已保存输入建立关节名称、合法初态和归一化合同，分离状态／图像因素，零新积分验证。
2. 从 A 的成功／失败记录评估放置阶段的姿态、支撑和撤手条件；报告误拒绝，不能将离线区分视作物理修复。
3. 将深度有效性、逐子步动作和研究／生产标签保持为数据读取回归。
4. 将支撑／力反馈新接触技能的候选设计及物理准入条件具体化，保存旧失败谱系；新技能的物理实验不由本次调度修订自动批准。

## 使用与验收

在项目目录运行下列入口，S 为上述接续目录的绝对路径：

```bash
python -B -m sage.experiments.embodied_continuous_v1.controller inspect "$S"
python -B -m sage.experiments.embodied_continuous_v1.controller run "$S"
python -B -m sage.experiments.embodied_continuous_v1.controller extend "$S" --jobs /absolute/path/jobs.json --reason '证据支持的具体后继'
python -B -m unittest sage.experiments.embodied_continuous_v1.test_controller -v
```

停止请求必须通过同一入口，例如 `close "$S" --reason deadline`；入口会重新验证理由。旧 R/tools/finalize.py 仅作历史证据，后续不得调用它作为新的整轮封存入口。
