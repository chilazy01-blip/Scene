# ADR 0001：V2 是唯一场景核心

- 状态：Accepted
- 日期：2026-09-01

## 决策

所有输入模态先归一化为共享 `SceneRequest` 和 `SceneBrief`。此后的资产、关系、布局、修复、装配与
验收只在 V2 实现。三个旧流程默认经过兼容 adapter，冻结算法仅用 `--legacy-engine` 显式复现。

## 原因

多条大入口重复实现相同步骤，使修复、默认值和验收范围持续漂移，也无法证明某个成功结果实际使用了
哪条算法。共享边界允许输入解释继续演进，同时保证后续语义和交付契约只有一份。

## 后果

旧 CLI 中无法无损表达的算法开关会被拒绝或仅记录为兼容注释，不再静默选择另一实现。动态事实由
`project_facts.py` 从 CLI、schema、runtime lock 和 release manifest 生成；手写文档不得复制这些值。
