配对执行没有改变放置参考的期望终点或抓取参考朝向，也没有改变释放决策。实测Codex两组进入释放时杯身直立余弦分别约0.92917、0.94590，原成功轨迹约0.97635。-30mm组在释放过程中明显侧倒；+30mm组在释放末尾已明显倾斜，随后在收手过程中继续倒下。近景和逐物理步姿态记录相符。

`ASSISTED_RELEASE_SUPPORT_DIAGNOSIS.json`同时保留反例：原成功轨迹在释放时也出现短时质心投影位于当时接触凸包之外；失败的Codex -30mm组还出现过短暂重新接触。因此，单帧支撑凸包或一次重新接触都不能独立作为通用成功判据，也不应直接收紧某个门限后把超时当作修复。
