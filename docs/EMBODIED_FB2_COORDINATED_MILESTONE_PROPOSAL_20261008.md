## 一次覆盖可预见的完整后续

1. 完成带历史联合验证：完整922参考、D7的601决策上下文、既有停止失败回归、计时和目标滞后、双分支与独立凸几何边界复核。对新轨迹保留足够的系数、起点、时长和状态记录，准备相匹配的物理worker、独立审计器与零积分执行器预检。测试的反事实范围必须写清，不能把旧实测轨迹当新控制器实际轨迹。任何未覆盖项继续阻止相应准入。
2. 仅在上述范围通过并冻结新候选后，追加**1次组件**：沿原初态完成接近、抓取、抬升至少5cm并保持，达到原phase300与双手接触/终态标准。最多1600命令、6400物理步、1600动态策略调用，最长32秒仿真时间。原保持超时3秒及各项物理质量门保持。首次物理、控制或任务失败即关闭，无自动第二候选。
3. 独立重建所有实际物理步、命令、策略输入、停止/恢复进度及接触。组件与审计均通过，并复查所有必需根因条目后，接续**原已有的1次完整任务**：最多2600命令、10400物理步、2600动态调用，最长服务870秒。失败即关闭，不能拿完整任务名额做组件诊断。
4. 完整任务及独立审计通过后，才执行原成功数据分支：同步RGB-D、数据质检、标准导出与实际Torch读取。仅原生场景的成功不能冒充自生成场景迁移、训练收益或量产验收。

科学失败分支都保留完整失败数据和已用费用。普通工程错误继续自主修复，但受下面统一累计额度约束。无新物理名额、无诊断渲染、无新下载；如最终无法准入或资源耗尽，给出具体失败和交接，不以局部回归通过冒领任务成功。
