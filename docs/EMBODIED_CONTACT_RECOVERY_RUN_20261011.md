## 两个明确的方法及共同工作

**C：实测接触反馈的就座与卸载。** 控制阶段为保持抓持、对齐、低速接近、检测承托、分步转移载荷、确认稳定、逐步松指、确认无手支撑、撤离。使用物体姿态与速度、目标承托接触力、手指接触和执行器实际状态反馈。发现倾斜、支撑不足或滑移时，保持抓持，回退到仍满足约束的预放置姿态，再调整后就座；禁止一检测到接触便无条件张手。单次任务内最多两次恢复，仍计在同一个300秒任务和全部子步记录中。

初始研究候选可采用倾斜不大于5度、承托竖直载荷至少为物重90%、低速状态持续0.2秒等条件；这些是需对已保存轨迹、噪声和力学尺度验证的控制设计值，不替代原生产验收，也不能直接写为已证明有效。仅靠静态接触支撑凸包会误拒绝原生成功样本，不能把该条件直接设为唯一松手门。承托载荷须按目标支撑与物体之间的接触单独统计，不把手指力或其他碰撞算入承托。

**D：以物体姿态和接触约束为目标的放置轨迹规划。** 当C的证据表明失败主要由接近方向、腕部可达姿态或沿途物体姿态造成时，采用显式规划的接近／放置轨迹：以物体与目标的相对姿态为优化目标，满足关节、执行器、碰撞及全身稳定约束，调整站位与腕姿，执行过程中重规划。与C的局部接触反馈原理区别须落实到优化变量、约束和实际代码；仅调C的增益、阈值或路点仍属于C，沿用其失败次数。

C和D各累计三次有效科学失败关闭该方法，累计总失败及旧A/B失败同时披露。8次开发额度共享，不给每阶段再设两次上限。两路均触发退出后不自动创建第三个名称继续同类试跑；继续共同质量诊断、接口／生成器／数据工程和具体后继准备。只有授权范围内有价值工作确实不能继续时，才提出附证据的范围决定。

**共同质量工作必须提前做。** 从已保存记录定位第一次超过10毫米穿透的时刻、几何对和实际指令，排查抓点、手指预载、模型几何、接触参数和积分敏感性。修复不得依靠降低碰撞检查、修改机器人或放宽10毫米门。材料、质量／惯量、摩擦与接触力阈值逐项核对依据；无法建立依据时保留研究结论，禁止称生产合格。原模型下的工程反例、短窗口校核使用诊断预算，不能把完整任务改名为诊断。
