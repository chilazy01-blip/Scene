# 条件仿真多模态数据契约

本页主体记录首批M的12条双相机契约，后文保留D与无损交付追加说明；当前合并数据已为44条完整RGB-D，统一以[训练入口](EMBODIED_TRAINING_DATA_20260927.md)为准。最新结果/接续见[当前交接](EMBODIED_LONG_RUN_HANDOFF_20260926.md)。

运行根：/data/wsj/main/scene_runs/codex_trellis_v2/embodied_stretch_ai_admission_20260926_v1/capability_multimodal。本页解释数据接口，实际完成数、质量与成本读RESULT.json和上级evidence/LONG_RUN_CHECKPOINT.json。

输入固定为6参考开发+6生成书房开发成功轨迹，每条实际运行27秒、13500物理步。没有使用留出、确认性评测或关闭的低桌配置来组成这批训练数据。图像从真实执行过的保存状态恢复，采集本身0积分。

~~~mermaid
flowchart LR
  A[实际成功轨迹 500Hz] --> B[保存状态恢复]
  A --> C[100Hz真实动作]
  B --> D[10Hz 双相机 RGB和深度]
  C --> E[每帧10步动作块]
  D --> F[规范HDF5与源哈希]
  E --> F
  F --> G[实际Torch读取与时间校验]
  G --> H[官方LeRobot无损RGB与动作块]
  F --> I[绑定的米制深度及掩码]
~~~

| 字段 | 形状或语义 | 类型与单位 |
| --- | --- | --- |
| RGB | 每相机270×192×256×3 | HDF5 uint8；原生读取float32 CHW/255 |
| 深度 | 每相机270×192×256 | float32，米，RGB光学中心理想配准 |
| 有效掩码 | 与深度同形 | bool，无效深度显式0 |
| K | 每帧3×3 | float64，从仿真实际视锥导出 |
| optical_to_base | 每帧4×4 | float64，机器人FK，可供部署式输入使用 |
| action_reference_chunk | 每帧10×10 | float64，100Hz原生命令，单位按执行器声明 |
| action_ctrl_chunk | 每帧10×10 | float64，内部重力前馈与限幅后的实际控制量 |
| joint_position/velocity | 每帧10维 | 原生执行器位置/速度，四段臂按既有映射 |
| previous_reference | 当前图像前一次100Hz参考 | 首帧使用home |
| next_joint_position/velocity | 动作块末端状态 | 对齐到下一个10Hz时刻 |
| done | 最后一帧为真 | 完整27秒覆盖，无跨episode动作 |

内参来自MuJoCo原生相机，不是厂商硬件标定；深度没有模拟真实D435双目基线、噪声或测量失败。没有雷达/IMU数据。头部相机与腕部相机的可见率按实际遮挡保留，不能用桌上物体成功抓取反推所有相机均提供目标信息。

特权字段包括分割、物体/相机世界坐标、物体质量、能力档位；它们可以用于来源追踪和质量统计，不进入公开训练样本。所有数据仍是条件仿真研究用途，未验证真机部署或广泛批量生产。

官方LeRobot导出中RGB以PNG嵌入Parquet保持无损。低维观测、动作块和时间字段通过官方Typed读取器核验。深度原件通过BINDING.json的相对路径与SHA256引用；移动整个capability_multimodal目录可以保留该关联。只拷贝datasets_lerobot会丢失深度，不能当成完整RGB-D包。标准导出可读不代表任意现成策略无需动作语义适配即可训练。

默认训练范围仅声明为开发集；本批没有独立视觉学习测试集，也没有视觉策略闭环结果。先前多样数据模型24/24来自时钟、初始几何和编码器的仿真复验，不属于这批RGB-D的视觉学习成绩。
