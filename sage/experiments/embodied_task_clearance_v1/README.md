# 保存状态工具净空与目标可见性

本模块读取上一轮冻结的四个机器人首次碰撞状态及四个释放终点，不求新 IK、不规划新路径、不积分。按原抓持关系重建完整状态，首次碰撞名称和深度须匹配旧证据。

对手掌和 link5 现有凸碰撞体进行固定 41×41 垂直采样。源支撑网格按闭合连通实体分别求内部区间再合并，保留缝隙；同位置与原支撑代理分别求重叠，保存区间、顶点和见证点。非闭合几何及奇数交点不作为无碰撞证明。正证据仅指源支撑与现有工具凸碰撞体重叠，不证明真实硬件干涉；无见证也不证明全局净空。13 条原生射线校验的是编译网格坐标及三角面，原生 mesh 射线不是凸包射线，二者不混用。

相机只检查保存的目标姿态。固定原 workspace、原 overview、一次从目标朝房间中心放置的室内相机规则；每视角一幅 RGB、完整场景分割和仅目标分割。至少 20 个可见及无遮挡目标像素、可见比例至少 50%，阈值事前登记。仅目标渲染只临时切换可视组；原资产、原模型文件和物理参数保持。

实际入口：

```bash
python -m sage.experiments.embodied_task_clearance_v1.entry \
  --record /absolute/path/evidence/VISIBILITY_FINAL.json \
  --sha256 <record_sha256> --camera overview_inward_rule_v1
```

入口核对模型、实现、协议、目标身份和原始分割后重算分数，检查通过才返回应用确定规则的原生相机。只允许 `target_visibility_inspection`，拒绝机器人执行、合格采集、合格导出。记录使用绝对证据路径，迁移证据需要显式重新绑定；没有改接旧生产管线，也没有机器人或时序观测资格。
