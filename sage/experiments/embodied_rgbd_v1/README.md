# 原生静态 RGB-D 观测接入

从 MuJoCo 实际投影视锥生成对应渲染分辨率的内参，以整数像素索引表示像素中心；将深度相机坐标变换至 RGB 相机，以最近深度投影并显式保留无观测区域。不会用补零图像替代相机，不填补投影空洞。

Stretch 原生 D435i 的 RGB 与深度相机相隔15mm；原生返回内参使用传感器分辨率，不能直接用于424×240图像。D405同位，无需外参重投影。真实保存深度分别经32条、32条 MuJoCo 射线核验；射线从渲染近裁剪面开始，避免将近裁剪面之前的相机外壳误当可见表面。

`export_snapshots` 保存有哈希绑定的静态HDF5观测，`SavedRGBDSnapshots`供真实Torch读取。所有记录明确为0动作转移、无执行任务、无训练资格；原始像素、旧错误内参及首次审计失败均保留。该接口用于观测接入和几何检查，不能替代完整轨迹验收。
