# 接触确认与保持控制

软件入口：`python -m sage.experiments.embodied_grasp_closure_v1 check STAGE`，必须由受限 CPU worker 调用。

`ClosureController`消费积分前的原生滑块位置/速度、原生执行器力、实际双侧接触力/垫比例、相对质心偏心量、被动垫速度以及严格1ms时戳。未接触时沿原参考闭合；实际接触达到名义承载下限和既定接触质量后进入确认，50ms连续合格后保持；失去质量20ms、额外压缩超2mm、速度/力越门、2秒未确认、无可用命令或非法输入均不得继续压紧。

保持参考为 `u=q-F_preload/kp`，对应原生模型的 `F=-F_preload-kd*v`，保留原生阻尼。额外力上限通过原生仿射驱动力公式约束当前命令，另对实际驱动力做检查；预测限幅不等于保证下一步真实力绝不越门。相对当前位移目标偏置≤8mm。XML、原生kp/kd、物性和原有任务门不修改。

参数统一按质量/摩擦先验及原生开口传动导数计算，不为杯子与瓶子分别调出成功：每侧承载下限 `mass*g/(2*mu)`，名义预载为下限×1.25×开口导数，执行器力门为预载×2。这是限定开发控制假设，不是实际硬件标定或力闭合证明。

保存轨迹的逐步消费仅验证状态机/接口能读取实际记录。新控制命令并未产生这些旧观测，不据此声明新控制会成功。新动态必须有独立冻结协议，并累计记录两开发组合的所有尝试。旧书本向量回归在本版本使用正确物体旋转，原始v1勘误记录保留。
