# 连续闭合控制 v2（软件接口）

`ClosureController.update(nominal, observation, applied)` 消费秒、米、米/秒、牛顿和弧度/秒。`applied` 是上一条确实发送的滑块参考，连续调用必须与上一输出一致。无效输入原子拒绝；物理越界进入不可恢复失败态。失败没有可发送指令，调用者必须停止积分。原生 `kp*(u-q)-kd*v` 不变。

首次双侧达到名义承载且垫/COM 合格时，精确保留 `applied`，从而保持同一状态下的努力连续。以后每步 `|Δu|≤Fprior/kp*dt/0.1s`，并与原生范围、±8mm目标偏置、原努力界限求交。交集空则拒绝，切换首步不可裁剪伪称连续。100ms是统一软件过渡尺度，未经动态标定；命令造成的力变化有界，不保证随运动变化的实际力也有界。

接触存在为双侧≥0.1N；名义承载仍为 `mg/(2μprior)`，与实际搬运稳定分别记录。确认期欠载清空准备窗口，在原2s总截止前等待；持续真正接触缺失20ms失败，有接触但垫/COM失格立即失败。保持期欠载立即取消准备，20ms后失败，恢复必须重新连续50ms。目标参考到达且持续50ms承载/部位/COM达标才算准备好；这不等价于试提通过。

`NativeTaskConsumer.consume(data, eight_named_native_actions, phase)` 直接读取完整 Stretch 模型的接触、惯性COM、原生力与被动关节速度，调用冻结的原生命名动作写入口。整个动作先校验，再推进控制/任务状态；拒绝不写ctrl。它不积分、不重设状态、不修改模型。`MjData`须为调用者当前已forward状态。支持 close→test_lift→test_hold→lift→transport→place；释放/撤回不在本软件适配器范围。只在真实原生消费路径收集test_hold的连续0.5s相对运动/离桌/支撑力窗口，调用`finish_trial()`后才能进入lift。实际搬运还须保留原任务全身/碰撞/姿态等运行门，本适配器不替代它们。

测试入口为 `python -m sage.experiments.embodied_grasp_closure_v2 check STAGE` 和 `audit STAGE`，必须在项目有限CPU服务内运行。软件入口禁用mj_step/step1/step2；合成窗口、保存状态命令探针和零时刻forward明确不计物理样本。旧轨迹在新命令首次分歧后只能作非因果接口流，不能冒充闭环，也不能将旧失败改标成功。

滑块广义力与每侧法向力分列；原零被动关节开口导数仅作预载先验。受载几何/接触虚功诊断不包含惯性、摩擦和被动动态，不当作力标定；旧quality的5N名义摩擦余量仍仅诊断。本版本不自动授予新的物理尝试或合格训练数据。
